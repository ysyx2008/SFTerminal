# 旗鱼想法本

点子先记在这里。想法会很多，一律记下，不筛。这不是待办清单：想法是还没验证的东西，没有「必须做完」的意思。讨论之后可能觉得不要做，也可能真的就做了；做了也可能不太满意，先搁在分支里，暂时不上线。想法要花时间才变成方案，方案要花时间才变成功能。这个本子就是那段时间差的收容所。

翻的时候看四堆：**未完成**、**已完成**、**做成了但不上线**、**不做了**。一条后来怎样了，对照提交和还没合进来的分支就能看出来——上线了就挪到已完成并挂提交；做了但不满意、还在分支里，挪到「做成了但不上线」并挂分支名；讨论后决定不做，挪到不做了，留一句为什么。**做完了就改本子**，不等下次才补。
