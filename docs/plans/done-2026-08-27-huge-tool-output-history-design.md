# 已完成 · 超大工具输出不拖死窗口

日期：2026-08-27

## 问题

命令超时或「还在跑」时，整段终端缓冲原样写进对话。缓冲里若是大段空字节、又几乎没有换行，一场对话能涨到几百兆。首页再按全文拉最近几场，窗口直接未响应。

## 取舍（已确认）

1. **写**：成功 / 超时 / 还在跑 / 在等输入，超预算一律落盘 + 指针 + 短摘要。
2. **采**：只丢掉连续很长的空字节（空格/换行/Tab 不动）；采集有安全上限，正常长日志仍整段落盘换指针。
3. **读**：列表只拉标题；点开按行跳过超大 jsonl，整场不扔；超大步只给大小、开头、结尾，或另存为文件。不在聊天里做成逐行翻几千万字的编辑器。
4. **不做**：不自动删已经写坏的历史文件。

- 共享类型用一处 `HugeOutputStub`，前后端不要各写一套。
