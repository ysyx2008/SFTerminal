# 产出物铺满（文档为主）设计方案

> 2026-08-21。**未完成。** 触发：用户认可 ChatGPT Work「文档占满 + 最近一条浮层」的阅读体验，要求先设计、不动手。
> 对照：现有桌的规矩见 `src/workbench/SPEC.md`（文件默认是右边参照）与 `packages/workbench-assistant/src/artifact/SPEC.md`。
> 完成后：稳定取舍升华进上述两份 SPEC 的设计目标，文件名加 `.done`。

## 1. 要解决的问题

左右分栏里，文档是参照、对话是主舞台。读长文档、改一章结尾时，真正要看的是文件；左边整栏对话（即便过程已收成一行）仍在占宽，150% 那种阅读出不来。

ChatGPT Work 的做法：文档铺满工作区，对话退成叠在文档上的「最近一条」，底下还能继续说。旗鱼要的是同一角色对调，不是再做一个真全屏（侧栏、会话列表都不动）。

## 2. 已确认

- 默认仍是左右分栏。短回复、几行 Markdown 不自动铺满。
- 人可以主动切到「文档铺满」。
- 真全屏（F11、藏侧栏）不做。
- 终端继续走现在的入座 / 让座，不要三栏，文档铺满不能把终端挤没。

## 3. 三种看文件的姿势

文件入座之后，只有两种看的方法；收起是离开座位，不是第三种看。

| 姿势 | 人看到什么 | 怎么进去 |
|---|---|---|
| **分栏**（默认） | 左对话、右文档，和现在一样 | 文件入座的默认 |
| **铺满**（新） | 文档占满工作区；对话流藏起；底下留下输入；文档上浮一句「它刚说的 / 它在忙什么」 | 文档工具栏上的布局按钮 |
| **收起**（已有） | 文档离座，对话独占 | 现在的收起按钮 |

终端入座仍是另一套座位：终端是工作面、对话陪右边。铺满只属于「文件/网页在座」时。

心智上：文件默认仍是参照（坐右）。人点铺满，这份文件临时变成工作面——和终端已经享有的「我是主角」同类，只是对话退得更干净（终端还留整栏对话，文档需要宽度，所以只留一句 + 输入）。

## 4. 铺满时桌面长什么样

```
┌─────────────────────────────────────────────┐
│  页签 …          保存  打开  ▾  [分栏|铺满] │  ← 现有文档顶栏，多一颗布局切换
├─────────────────────────────────────────────┤
│                                             │
│              文档（可读、可划选）              │
│                                             │
│          ┌─────────────────────┐            │
│          │ 它刚说的那句 / 在忙什么 │            │  ← 浮层，居中偏下
│          └─────────────────────┘            │
├─────────────────────────────────────────────┤
│  排队（若有）                                 │
│  输入框（含附件、提及、即将到来的 / 命令）      │  ← 垫在文档底下，占布局，不盖住正文
└─────────────────────────────────────────────┘
```

工作台右上角现有的清单、收起不动。清单换文件、收起离座，和现在同一套。

## 5. 浮层里放什么

沿用对话流已经定下的口径，不另写一套摘要：

| 此刻 | 浮层 |
|---|---|
| 闲着，上次说过话 | 它说出口的那句（过长先收着，点开在卡片里展开） |
| 正在做 | 过程那一行：在忙什么 + 走秒（与对话流同一句话） |
| 要你动手 | 确认危险命令 / 问你问题 / 等你输密码——完整出现，不能收成一句 |
| 还没说过话 | 浮层不出现，只留输入 |

不做：点赞点踩、「打开方式」、再贴一份文件卡片（文档已经在舞台上）、标题写成「最近一条」。卡片就是那句话本身。

点卡片：只展开 / 收起这句，**不**切回分栏。回分栏只走顶栏布局按钮。看文档时误点一句就冲回分栏，会打断阅读。

## 6. 输入框为什么垫着、不浮着

ChatGPT 的输入条轻，可以叠在文档上。旗鱼的输入更重：排队、附件、提及、斜杠命令。叠上去会经常挡住正文最后几行。

所以输入占文档底下一条固定高度，文档在它上面结束。浮层坐在输入上方、文档里，不挡工具栏。

划选改文档的闭环不变：划完直接在底下打要求；选区提示仍贴着选中的字；右键五项快捷指令当场发出。

## 7. 何时进入 / 退出 / 记住

**进入**

- 只靠人点文档顶栏的布局按钮。
- 不按文件类型自动切（不猜「这是不是长文档」）。
- 助手新写出东西：若当前已是铺满，留在铺满并换成这份；若在分栏，仍分栏。

**退出铺满（回到分栏）**

- 再点同一颗布局按钮。
- 终端入座（换座）时自动回到「终端工作面 + 对话在右」——铺满只属于文件在座。

**离开座位（不是退出铺满）**

- 收起、关光页签：文档离座，对话独占。下次再入座，从分栏开始。

**记住**

- 只在「这一次文件在座」期间记住。换页签、点清单换文件，保持铺满。
- 离座后再打开，回到分栏。不写进历史、不跨会话。

## 8. 和现有规矩怎么接

- **过程折叠**：铺满不改折叠规则。过程仍是那一行，只是出现在浮层而不是对话流里。严格模式仍然不折叠——但铺满时对话流本就看不见，过程那一行照样按严格/宽松出现在浮层（严格下会啰嗦一些，可接受；不为铺满另做一套）。
- **排队 / 插入 / 编辑排队**：仍在输入框上方，规则不改。
- **目标胶囊**（若届时已落地）：跟排队一样，贴在输入上方，不进浮层。
- **人机双写 / 选区**：铺满时更用得上，行为不改。
- **冲突横幅**（AI 改了盘、你有未保存）：仍在文档顶，不进浮层。
- **网页缩放**：已有，铺满后更有用，不另做。
- **换座**：铺满中助手打开终端 → 文件让开、终端入座（现有）。人再从清单请回文件 → 分栏入座（离过座，不恢复铺满）。
- **联络 / 终端页**：不动。只做独立助手这张桌。

## 9. 明确不做

- 不按类型、字数、标题自动铺满。
- 不做系统全屏，不藏历史侧栏。
- 不为铺满另请模型写一句漂亮人话。
- 不把终端也改成「一句浮层」（终端已有自己的对话开合）。
- 不把铺满写成第三种座位——座位仍是「空 / 终端 / 文件」，铺满是文件在座时的看的方法。
- 一期不做铺满偏好写进设置、不跨会话记忆。

## 10. 实现落点（动手时用，现在不动）

跨两个模块，需你确认后再改：

| 模块 | 文件 | 做什么 |
|---|---|---|
| 助手工作台 | `AssistantWorkbench.vue` | 文件在座时增加 `focus` 姿势；铺满时文档吃满、对话列改成底栏 |
| 产出物面板 | `ArtifactPanel.vue` | 顶栏加分栏/铺满切换（与「打开」一组，不挤进工作台右上那组） |
| 对话岗壳 | `AiPanel.vue` | 铺满态：藏消息列表，露出「最近一句 / 过程行 + 确认/提问/密码 + Composer」 |
| 文案 | `src/i18n/locales/{zh-CN,en-US}/canvas.ts` | 布局切换的名字与提示 |
| 设计目标 | `artifact/SPEC.md`、`src/workbench/SPEC.md` | 动手前写入本节已确认的取舍 |

`WorkbenchShell` 的「锚点 + 右侧辅助」不够表达「文档是锚、对话变底栏」。铺满时工作台自己排，不硬拧 Shell。

状态：`focus` 是 tab 级、只活在这次入座，不进产出物历史快照，Agent 不必感知（`list_workbench_artifacts` 不为此加字段）。
