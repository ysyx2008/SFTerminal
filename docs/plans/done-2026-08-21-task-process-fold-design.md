## 定稿形态（第三轮，推翻前两轮的展示方式）

一个任务在界面上只有两种东西：**它说给你听的话**永远在外面（对话主体），**它做事的过程**永远收着一行（附属）。

那一行从任务开始到结束**位置不动、行数不变、只换内容**——不是"做完才收"，而是压根没展开过，因此没有任何东西冒出来又消失。

```
在查上个月的账 · 读了 2 个文件 · 18s   ◐   ← 跑着，秒数实时走，右侧转环
查了日程，读了 3 个文件 · 24s          ›   ← 做完，转环原地变箭头
```

- **无左侧图标、无底色**，左边缘与正文对齐；hover 才浮出淡背景。箭头/转环都在**文字右侧紧跟**（不贴容器右边缘）
- 运行中文案优先用它自己刚写下的那句思考，没有就退回动作分类
- **过程中的工具失败收进去**，展开才看得到；只有整件事没办成才在外面
- **要你动手的永远在外面**：确认危险命令、问你问题、等你输密码
- **产出物在外面**：图表、搜索结果、它主动发出去的消息
- **一视同仁**：新旧任务一个样，只收过程不收它说的话
- **任何任务都收**，哪怕只跑了一步——形态始终一致，不存在有时收有时不收
