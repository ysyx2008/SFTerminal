# 应用菜单 SPEC

> Last verified: 2026-08-21

## 职责

系统菜单（macOS 顶栏、Windows 汉堡菜单）是键盘党与菜单栏用户进出各个地方、做终端操作的另一条路。它必须跟侧栏说同一种话，不能停在「旗鱼终端」时期的旧地图上。

## 设计目标

壳层已经改成三个固定入口：新对话、联络、终端；秘书菜单里还有待办、关切。菜单很久没跟着改，栏名、用词、快捷键都还停在旧产品上。

成功标准：

- 菜单先让人「去某个地方」，再让人「在这个地方做事」——跟侧栏同一张地图
- 「收起 / 展开最近对话」和窗口左上那个按钮是同一件事；`⌘B`（及对等快捷键）绑在这里，不再误开主机管理
- 「收起 / 展开侧边栏」指终端里那块对话栏，只在终端界面上能用，不跟最近对话抢同一个名字
- 主机管理有自己的名字，不再叫「切换侧边栏」
- 「新建（跟随当前位置）」这种实现口径不出现在菜单里；按当前位置新建仍是快捷键的事
- Steam 版不露出助手相关入口

关键取舍：

- **单独加「前往」一栏**，不把三个地方塞回「终端」栏。终端栏只放终端的事
- **连接远程主机**和**管理主机**都打开主机列表，但意图不同：前者先落到终端再打开，后者只开关主机列表（可关掉）
- 菜单文案跟界面已有说法对齐（新对话 / 联络 / 终端 / 待办 / 关切 / 最近对话），不另造一套词

明确不做：

- 不把「按当前位置新建」做成菜单项
- 不把觉醒、智能巡检放进菜单（入口仍在侧栏 / 欢迎页）
- 不在菜单里做「查找」——发送后没有人接，先不露出来
- 不改托盘菜单，不改 CLI
- 不为这次改动另做一套菜单翻译体系

## 行为契约

**前往**

- 新对话、联络、终端：与侧栏三个入口同一去向
- 待办、关切：与秘书菜单里那两项同一去向
- 后退 / 前进：与窗口里已有的后退前进同一套历史
- Steam 版不出现新对话、联络、待办、关切

**终端**

- 打开本机终端：立刻开一个本机终端
- 连接远程主机：先到终端这个地方，再打开主机列表，让人挑机器连
- 管理主机：只开关主机列表，不改变人现在在哪个地方
- 批量操作、文件管理器、导入 Xshell、分屏、关窗格、关标签：仍是终端里的事；没有终端时，批量操作和文件管理器都不可用
- 文件管理器或 AI 调试控制台开着时，关闭（`⌘W` / `Ctrl+W`）先关掉它们，不碰主窗口里正在看的内容

**编辑**

- 系统标准编辑项保留
- 清屏仍在这里，只对当前终端有意义

**视图**

- 收起 / 展开最近对话：收起或展开左边那列最近对话，不是主机列表
- 收起 / 展开侧边栏：只对眼前的终端界面有意义；不在终端时这项不可用
- 记忆与知识库仍是跳进控制面板对应页，不是一块能开关的面板
- 缩放、全屏、开发者工具、重新加载保留
- Steam 版不出现对话面板、记忆与知识库、调试控制台

**旗鱼 / 窗口 / 帮助**

- 关于、控制面板、退出、窗口操作、文档与更新：保持原样
