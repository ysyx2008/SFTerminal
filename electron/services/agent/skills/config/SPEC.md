# 旗鱼配置管理技能 SPEC

> Last verified: 2026-08-19

## 职责

让秘书能替用户查看和调整旗鱼自己的设置：界面、终端、渠道凭证、邮箱/日历账户、MCP 连接器，以及 AI 模型配置。设置页仍然可用，两边改的是同一份。

## 设计目标

### 秘书要能管模型，不必把人赶到设置页

用户会说「帮我加个 DeepSeek」「看看现在有哪些模型」。这和「帮我加个邮箱」「接一个 MCP」是同一类事，不该只有设置页能做。

- **能看清已有模型**：名字、模型名、接口地址、类型、是不是当前默认、Key 填了没有。不能只报「有几项」。
- **能加、改、删**：一条一条来，禁止整表覆盖把已有模型冲掉。
- **Key 不回显**：对话里只说「已配置 / 未配置」，不把密钥原文带出来。
- **第一条自动成为默认**；删掉当前默认时，切到剩下的第一条。新加的第二条起不自动抢走当前正在用的默认（除非用户明确要求设为默认）。
- **尽量测一下能不能连上**：测失败也先存下来并说明原因——设置页也允许不测就保存。
- **不做**：不替用户猜供应商默认地址；不自动把新模型切到当前正在聊的这次会话。

### 列表型配置一律走「加一条 / 改一条 / 删一条」

邮箱、日历、MCP、AI 模型都是列表。整表写入会覆盖别人已经配好的项，所以列表本身只读展示，增删改走专用入口。
